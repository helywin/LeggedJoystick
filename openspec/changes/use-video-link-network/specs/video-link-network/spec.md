# Spec Delta

## Purpose

依据遥控器当前活动网卡的本地 IPv4 网段选择机器狗底盘通信入口，使图传与 Wi-Fi 切换后，控制、主控业务和头尾视频使用同一可预期的底盘地址。

## ADDED Requirements

### Requirement: 按本地 IP 网段确定底盘入口
App MUST 从当前活动网卡本地 IPv4 地址判断通信入口，不得根据遥控器型号判断。`192.168.168.0/24` MUST 对应 `192.168.168.168`，`192.168.144.0/24` MUST 对应 `192.168.144.144`，`192.168.234.0/24` MUST 对应 `192.168.234.1`。多个已知网段同时存在时 MUST 优先图传。

#### Scenario: 思翼图传网段
- **WHEN** 活动网卡具有 `192.168.168.20` 等 `192.168.168.0/24` 地址
- **THEN** App 选择底盘 `192.168.168.168`

#### Scenario: 另一图传网段
- **WHEN** 活动网卡具有 `192.168.144.0/24` 地址且无更高优先级图传网段
- **THEN** App 选择底盘 `192.168.144.144`

#### Scenario: Wi-Fi 热点网段
- **WHEN** 活动网卡只具有已知的 `192.168.234.0/24` 地址
- **THEN** App 选择底盘 `192.168.234.1`

### Requirement: 控制与视频地址一致
App MUST 在加载设置与每次发起连接前重新判断本地网段。对于已知的标准底盘地址和头尾 RTSP 路径，控制 `33445`、主控 `33446`、头尾 RTSP `8554` MUST 使用当前选中的同一底盘地址。非标准手工地址 MUST 保留。

#### Scenario: 从热点切到图传
- **WHEN** 已保存的地址为热点标准入口，活动本地地址进入 `192.168.168.0/24`
- **THEN** 发起连接时控制和默认头尾视频地址使用 `192.168.168.168`

#### Scenario: 手工配置其他入口
- **WHEN** 用户保存了非标准机器人地址或 RTSP 路径
- **THEN** 网段识别不覆盖这些手工值

### Requirement: 未知网段不猜测入口
App MUST 在没有匹配的活动本地网段时保留当前保存地址，不得凭遥控器型号改用另一网段。连接失效后 MUST 沿用现有零速度保护。

#### Scenario: 图传接口尚未就绪
- **WHEN** 没有已知网段的活动本地 IPv4 地址
- **THEN** App 不改写控制和视频地址，连接失败时停止持续运动输出
