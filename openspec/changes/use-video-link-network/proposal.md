# Proposal

## Why

遥控器通过图传或 Wi-Fi 接入时，本地 IP 网段不同。App 固定保存一个底盘地址会在切换链路后连接到错误入口，需要让控制和视频地址随当前本地网络变化。

## What Changes

- 读取活动网卡本地 IPv4：`192.168.168.*` 对应底盘 `192.168.168.168`，`192.168.144.*` 对应 `192.168.144.144`，`192.168.234.*` 对应 `192.168.234.1`。
- 同时存在多个已知网段时优先图传；控制 `33445`、主控 `33446` 和头尾 RTSP 使用同一底盘地址。
- 启动加载设置与连接前重新选择标准入口，保留非标准手工地址。
- 构建签名 APK，并将巡检版安装到当前 ADB 连接的思翼遥控器。

## Capabilities

### New Capabilities

- `video-link-network`: 定义本地 IP 到底盘入口的映射、地址联动和未知网络行为。

### Modified Capabilities

- 无。

## Impact

- 影响 Android 设置读取、连接前地址选择和视频 URL；不改变摇杆输入、协议或图传设备内部传输。
